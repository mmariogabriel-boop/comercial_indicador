O relatório PDF considera o recorte atual dos filtros:
- Competência
- Material
- Corretora
- Vendedor

O PDF contém:
- resumo executivo;
- Saúde e Odonto por competência;
- Vendido x Meta de Saúde;
- Vendido x Meta de Odonto;
- produção por executivo;
- produtos mais vendidos;
- maiores corretoras;
- maiores vendedores;
- ranking por entidade;
- distribuição por tipo de produto;
- regras utilizadas.

IMPORTANTE SOBRE METAS
Quando Material, Corretora ou Vendedor estiverem filtrados, o "Vendido"
é recalculado para o recorte selecionado, mas a meta continua sendo
a meta corporativa mensal cadastrada no dashboard.

COMO USAR
1. Suba as duas planilhas.
2. Aplique os filtros desejados.
3. Clique em "Gerar relatório PDF".
4. Clique em "Baixar relatório PDF".

REGRA DEFINITIVA DE COMPETÊNCIA - PRODUÇÃO X EVASÃO

PRODUÇÃO
Competencia_Producao = Data Inclusão Vida

EVASÃO
Competencia_Evasao = Data Fim Beneficiário

O filtro central de competência é aplicado separadamente:
- na Data Inclusão Vida para Produção;
- na Data Fim Beneficiário para Evasão.

Exemplo:
Uma vida incluída em 03/2026 e cancelada em 09/2026:
- conta como Produção em 03/2026;
- conta como Evasão em 09/2026;
- o cancelamento não altera a competência original da produção.

SALDO MENSAL
Saldo = Produção do mês - Evasão do mês


CORREÇÃO DE COMPATIBILIDADE - PDF / STREAMLIT CLOUD

Foi corrigido o tratamento dos nomes utilizados nos gráficos do PDF.

Problema anterior:
o Pandas do Streamlit Cloud podia entregar valores numéricos/nulos no índice
do ranking de executivos, e o código tentava executar len() diretamente nesses valores.

Correção:
- todo nome é convertido explicitamente para texto;
- valores nulos viram "Não informado";
- ranking genérico recebeu a mesma proteção;
- quantidades são convertidas com pd.to_numeric antes do gráfico.

Essa correção não altera nenhuma regra comercial ou cálculo.


CORREÇÃO DE ESTABILIDADE - STREAMLIT CLOUD

O Dashboard Comercial foi otimizado para reduzir o uso de memória:

1. A Base Total não é mais lida novamente para calcular a evasão.
2. A evasão é derivada da base já processada em memória.
3. Apenas as colunas necessárias são copiadas para a base de evasão.
4. O processamento principal usa st.cache_resource com uma única entrada.
5. A leitura Excel não mantém um segundo cache da Base Total.
6. matplotlib/reportlab só são importados quando o usuário clica em Gerar relatório PDF.
7. Uma falha na geração do PDF não derruba mais o restante do dashboard.

REGRAS DE COMPETÊNCIA MANTIDAS:
- Produção -> Data Inclusão Vida
- Evasão -> Data Fim Beneficiário
